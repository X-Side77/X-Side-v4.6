X-SIDE VST3 v4.4 CLEAN

Чистый проект для нового GitHub-репозитория.

Проверка версии:
- CMakeLists.txt: project(XSide VERSION 4.4.0)
- В интерфейсе: CLEAN v4.4
- Artifact: X-Side-v4.4-Windows-x64

Что входит:
- Source/
- Resources/factory_presets.json
- CMakeLists.txt
- .github/workflows/build-windows-vst3.yml

Как загрузить:
1. Создать НОВЫЙ пустой GitHub repository.
2. Распаковать архив.
3. Загрузить содержимое архива в корень репозитория.
4. Папку .github/workflows при необходимости создать вручную через Create new file.
5. Actions -> Build X-Side VST3 v4.4 Windows -> Run workflow.
6. После Success скачать Artifact X-Side-v4.4-Windows-x64.
